# ProposalMatch Cloud — Despliegue en Railway

## 🚀 Cómo desplegar (5 minutos)

### Opción 1: Deploy automático desde GitHub (RECOMENDADO)

1. **Ve a Railway**
   - Abre https://railway.app
   - Click en "New Project"

2. **Conecta GitHub**
   - Selecciona "Deploy from GitHub"
   - Conecta tu cuenta de GitHub
   - Selecciona el repo `proposalmatch`

3. **Railway despliega automáticamente**
   - Espera 2-3 minutos
   - Railway te da una URL como: `proposalmatch-production.up.railway.app`

4. **¡Listo!**
   - Tu URL está lista
   - Solo comparte el link

## 🔒 Seguridad garantizada

✅ **PDFs se borran inmediatamente**
- Se procesan en memoria
- Se guardan máximo 30 minutos en /tmp
- Se limpian automáticamente

✅ **HTTPS automático**
- Railway proporciona certificado SSL gratis
- Todos los datos encriptados en tránsito

✅ **Sin almacenamiento persistente**
- No hay base de datos de PDFs
- No hay logs de documentos
- Cada sesión es independiente
